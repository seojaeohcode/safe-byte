# V2 작업 완료

작업 브랜치: `v2-redesign`. 기존 `mobile/`, `web/`, `hardware/` 변경 없음. 실행한 데모와 캡처는 목업 데이터만 사용했으며 서버를 만들거나 실행하지 않았습니다. 커밋 대상은 `V2/`만이며 push하지 않습니다.

## 직접 캡처 검토와 수정

초기 렌더를 검토한 뒤 세 차례 보정했습니다.

1. 홈 하단이 접힌 위치에 걸리던 간격을 조정하고, 결과 제목의 아랍어 대체 글꼴을 보완했습니다. 가족 편집을 기준 설정과 같은 구조로 정리했습니다.
2. 일본어·중국어 누락 문자를 번들 글꼴로 보완하고, 장보기 수량을 상품 행 안에 배치했습니다. 연결과 종료는 상단 도구 영역에서 접근합니다.
3. CJK 변수 글꼴의 기본 굵기로 일부 문자가 가늘게 보이던 문제를 400/700 정적 글꼴과 언어별 기본 글꼴로 해결했습니다. 안전 상태 배경 대비를 미세 조정했습니다.

최종 캡처에서 한글·일본어·중국어·아랍어 표시, 결과 위계, 코드 숫자 방향, 홈 하단과 장보기 상품 행을 확인했습니다. 필수 화면의 과한 색·장식, 레이아웃 오버플로, 누락 글리프 문제는 발견하지 못했습니다.

## 남은 사항과 범위

알려진 필수 화면 UI 오류는 없습니다. 실제 Android 기기의 카메라·앨범 권한, Bluetooth, 운영 API, NAVER CLOVA OCR 호출은 이번 목업 검증 범위에서 실행하지 않았습니다. 기존 클라이언트 연결 코드는 유지했습니다.

목업 API는 화면 검토용 고정 데이터입니다. 실제 인증·영구 저장·상품 수량 변경 서버를 구현하지 않으며, 키오스크 연결도 실제 기기를 인증하지 않습니다. 긴 실제 OCR 원문과 많은 상품·기준은 스크롤로 확인합니다. 골든 비교는 문서화한 Flutter·Windows 글꼴 렌더 환경을 기준으로 합니다.
